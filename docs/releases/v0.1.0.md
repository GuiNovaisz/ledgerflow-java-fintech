# LedgerFlow v0.1.0 — Initial Portfolio Release

**Status:** Locally verified release candidate; public publication awaits owner approval. MIT licensed.

## Overview

LedgerFlow is an educational backend project that demonstrates account ownership, concurrency control, retry safety, and auditable history in a small simulated ledger. It moves no real money and does not connect to financial institutions or payment services.

## Features

- JWT-based registration and login with BCrypt password hashing.
- Owner-scoped BRL accounts that can be activated or deactivated.
- Simulated deposits, withdrawals, and transfers recorded as immutable ledger postings.
- Paginated entry history, UTC date-range summaries, and CSV statements.
- Docker Compose local environment, PostgreSQL migrations, and OpenAPI UI.

## Technical Highlights

The service uses a modular monolith architecture with Spring Boot and PostgreSQL. Monetary values use `BigDecimal` and fixed-scale database decimals. Each financial operation changes balances and writes ledger postings within one transaction. Row locks coordinate balance updates, while transaction-scoped PostgreSQL advisory locks coordinate requests using the same idempotency key. CSV output neutralizes spreadsheet formulas in user-controlled text.

Coverage includes owner isolation, JWT validation, retry idempotency, concurrent spending, opposite transfers, rollback, immutable postings and nanosecond report-boundary regression.

## Getting Started

See the [README](../../README.md) for Docker Compose quick-start instructions. Docker Compose builds the application with JDK 21; running Maven builds or tests on the host requires JDK 21. PostgreSQL integration tests additionally require a working Docker-compatible engine. Compose binds service ports to loopback by default.

## Known Limitations

- BRL only; no fractional cents, currency conversion, fees, interest, or external settlement.
- This is an internal account ledger, not a complete double-entry general ledger.
- Access tokens expire after 15 minutes; refresh tokens, immediate revocation, rate limits, MFA, and KYC/AML flows are not implemented.
- No production deployment, operational monitoring, external reconciliation, or compliance controls are provided.
- Local verification is not a penetration test or production security certification; Maven advisory scanning does not cover container OS packages or build plugins.

## Next Steps

Potential future work includes reconciliation and audit tooling, operational monitoring, and stronger identity and abuse controls. These require separate product and architecture decisions.
